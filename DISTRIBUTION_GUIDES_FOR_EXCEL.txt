TABLE 2: DSM LIFETIME DISTRIBUTIONS
Sheet: 3_1_Definition_DSM
================================================================================

Distribution_Type	Parameters_Required	Description	When_To_Use	Example	StdDev_Warning
Fixed	DSM_Lifetime_Mean	All items leave at EXACTLY the specified age (no variation)	Items with regulated lifetimes, safety equipment with expiry dates, strict replacement schedules	Fire extinguishers (10 years fixed), Light bulbs (5000 hours)	N/A - No variation
Normal	DSM_Lifetime_Mean, DSM_Lifetime_StdDev	Bell curve distribution - most items leave near mean, some earlier/later	Products with typical wear-out, building components, consumer goods	Vehicles (mean=15, std=3), Appliances (mean=12, std=2)	⚠ If StdDev > 80% of Mean, too much variation!
LogNormal	DSM_Lifetime_Mean, DSM_Lifetime_StdDev	Skewed distribution with long tail to right - many early failures, some last very long	Electronics with infant mortality, machinery with maintenance variability	Industrial equipment (mean=10, std=5)	✓ Cannot produce negative ages
FoldedNormal	DSM_Lifetime_Mean, DSM_Lifetime_StdDev	Normal distribution "folded" at zero - ensures no negative ages	When Normal is appropriate but want to avoid negative artifacts	Short-lived products, packaging materials	✓ Similar to Normal but cleaner
Weibull	DSM_Lifetime_Scale, DSM_Lifetime_Shape	Very flexible - can model bathtub curve, infant mortality, or wear-out	Complex failure patterns, mechanical systems, empirical failure data	Building facades (Scale=12, Shape=2.5 for wear-out)	Shape<1: early failures, Shape=1: constant, Shape>1: wear-out

DECISION TREE:

1. Fixed age requirement (legal/safety)? → Use Fixed
2. Typical lifetime with symmetric variation? → Use Normal or FoldedNormal
3. Early failures + long survivors (skewed)? → Use LogNormal
4. Complex failure patterns? → Use Weibull
5. Not sure? → Use Normal (most common in literature)

PARAMETER GUIDELINES:

Normal/FoldedNormal:
• Typical StdDev = 10-30% of Mean
• Example: Mean=10, StdDev=2 → 95% leave between 6-14 years
• ⚠ If StdDev > 0.8×Mean → unrealistic variation

Weibull Shape interpretation:
• Shape = 1.0 → Constant failure rate
• Shape = 2.0 → Moderate wear-out
• Shape = 3.5 → Strong wear-out

TABLE 3: MONTE CARLO UNCERTAINTY DISTRIBUTIONS
Sheet: 4_1_Uncertainty_Parameters (or MC sheet)
================================================================================

Distribution_Type	Parameters_Required	Description	When_To_Use	Example	Parameter_Guidelines
uniform	min, max	All values between min and max equally likely (rectangular)	Complete uncertainty, only know range, expert "at least/at most"	Waste composition: min=0.10, max=0.30	Use when no preference for middle values
triangular	min, mode, max	Triangle-shaped - most likely at mode, tapering to min/max	Expert estimates with "best guess", three-point estimates	Carbon: min=0.40, mode=0.45, max=0.50	Mode can be anywhere between min/max
normal	mean, std	Bell curve - 68% within ±1std, 95% within ±2std	Measurement data, normally distributed errors	Lab measurements: mean=100, std=5	⚠ Can sample negative if std too large!
lognormal	mean, std	Skewed bell curve - cannot be negative, long tail right	Positive-only parameters (prices, rates), multiplicative uncertainties	Material costs: mean=100, std=20	Always positive, median < mean

ACTUAL IMPLEMENTATION NOTES:
✗ Beta distribution - NOT CURRENTLY IMPLEMENTED
✗ TruncatedNormal - NOT CURRENTLY IMPLEMENTED

DECISION TREE:

1. Measured data with standard deviation? → Use normal
2. Only know range (min/max)?
   - With "best guess" → Use triangular
   - Without best guess → Use uniform
3. Always positive with potential outliers? → Use lognormal
4. Not sure? → Use triangular (simplest for experts)

PARAMETER GUIDELINES:

Uniform:
• Most conservative (widest uncertainty)
• Use for "absolute bounds"

Triangular:
• Min = pessimistic, Mode = most likely, Max = optimistic
• Mode doesn't need to be centered

Normal:
• If coefficient of variation (std/mean) > 0.3, consider lognormal
• ⚠ Can produce negatives if mean < 3×std

RULE OF THUMB:
• Low uncertainty (±5-10%): normal or triangular with narrow range
• Medium uncertainty (±20-30%): triangular or normal
• High uncertainty (±50%+): uniform or lognormal
