# BioDYM Documentation

This directory contains documentation for the BioDYM Material Flow Analysis tool.

## Documentation Structure

### User Manual (`manual/`)

A complete LaTeX-based user manual covering all BioDYM features:

- `biodym_manual.pdf` — Compiled PDF manual (ready to read)
- `biodym_manual.tex` — LaTeX source
- `chapters/` — Individual chapters (installation, workflow, DSM, FOMP, Monte Carlo, etc.)
- `appendices/` — Distribution functions, Excel reference, troubleshooting

### Workflow Diagrams

- `workflow_diagram.pdf` — BioDYM analysis workflow diagram (PDF)
- `workflow_diagram.drawio` — Editable source (DrawIO format)
- `workflow_explained.pdf` — Detailed workflow explanation

### Methodology

- `METHODOLOGY_CHAPTER_DRAFT.md` — Draft methodology chapter for publication

### Developer Documentation (`development/`)

Resources for contributors and maintainers:

- `CODING_STANDARDS.md` — Code quality standards and naming conventions
- `TECHNICAL_DEEP_DIVE.md` — In-depth technical documentation (data flow, solver algorithm)
- `TROUBLESHOOTING.md` — Common issues and debugging strategies
- `ENGINE_STRUCTURE_ANALYSIS.md` — Engine architecture review and ratings
- `BIODYM_ARCHITECTURE_GUIDE.md` — Project architecture overview
