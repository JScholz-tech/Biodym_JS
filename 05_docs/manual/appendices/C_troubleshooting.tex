\chapter{Troubleshooting}
\label{ch:troubleshooting}

\section{Installation Issues}

\begin{description}
  \item[``uv: command not found''] Install uv: \texttt{curl -LsSf https://astral.sh/uv/install.sh | sh} (Linux/macOS) or see \url{https://docs.astral.sh/uv/} for Windows.

  \item[Tests fail after installation] Run \texttt{uv sync} again to ensure all dependencies are installed. Check that Python 3.13+ is available: \texttt{python --version}.

  \item[Jupyter won't start] Ensure Jupyter is installed: \texttt{uv run pip install jupyterlab}. Then retry \texttt{uv run jupyter lab}.
\end{description}

\section{Data Loading Errors}

\begin{description}
  \item[``Sheet not found''] The Excel workbook is missing a required sheet. Check that all sheet names match exactly (including underscores and case).

  \item[``Column X not found''] A required column is missing or misspelled. Compare your sheet headers with the reference in Appendix~\ref{ch:excel-ref}.

  \item[``No data for flow F\_XX\_YY''] The flow is defined in sheet \texttt{1\_1} but has no data in sheet \texttt{1\_2}. Add at least one data point.

  \item[Decimal separator issues] BioDYM expects the period (\texttt{.}) as decimal separator. If your Excel uses commas, either change the system locale or save as CSV with periods.
\end{description}

\section{Calculation Errors}

\begin{description}
  \item[Solver does not converge] Check for circular flows without a stock process. The iterative solver needs at least one stock (or boundary) to break circular dependencies.

  \item[Mass balance error $>10^{-3}$] \hfill
  \begin{itemize}
    \item TCs not summing to 1.0 --- check all outflow TCs per process
    \item Missing outflow for a process that receives inflow
    \item Element composition fractions exceeding 100\%
  \end{itemize}

  \item[Negative stock values] DSM lifetime parameters may be misconfigured. If using Normal distribution, check that \texttt{StdDev} $< 0.8 \times$ \texttt{Mean}. Consider switching to FoldedNormal or Weibull.

  \item[DSM element stock drops to zero] If non-material element stocks (WC, DM, CC) drop to zero when inflow stops, update to the latest BioDYM version. This was a known bug fixed with cumulative composition tracking.
\end{description}

\section{Visualization Issues}

\begin{description}
  \item[Plots not showing in Jupyter] Ensure \texttt{plotly} is installed: \texttt{uv run pip install plotly}. Use JupyterLab (not classic Jupyter Notebook) for best compatibility.

  \item[Export produces blank image] Install \texttt{kaleido} for static image export: \texttt{uv run pip install kaleido}.

  \item[Small text on exported PNGs] Increase the \texttt{scale} parameter: \texttt{fig.write\_image("plot.png", scale=3)} for 300~DPI.
\end{description}

\section{Monte Carlo Issues}

\begin{description}
  \item[MC always returns same results] Check that the \texttt{Distribution\_Type} column is spelled correctly (lowercase: \texttt{normal}, \texttt{uniform}, \texttt{triangular}, \texttt{lognormal}).

  \item[High rejection rate] If many samples are rejected during TC normalization, your uncertainty ranges may be too wide. Narrow the \texttt{Min}/\texttt{Max} bounds or reduce \texttt{StdDev}.
\end{description}
