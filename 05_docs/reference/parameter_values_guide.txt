║  WEIBULL SHAPE PARAMETER (DSM)                                               ║
║  ══════════════════════════════════════════════════════════════              ║
║  Purpose: Controls failure rate pattern over product lifetime                ║
║                                                                               ║
║  Shape   Failure Pattern        Example Products                             ║
║  ─────   ──────────────────     ───────────────────────────────────          ║
║  0.5-0.8 High infant mortality  Prototype electronics, early failures        ║
║  1.0     Constant failure rate  Light bulbs, random failures                 ║
║  1.5-2.0 Moderate wear-out      Consumer electronics, standard equipment     ║
║  2.5-3.5 Strong wear-out        Tires, bearings, mechanical parts            ║
║  >4.0    Rapid wear-out         Safety components with strict replacement    ║
║                                                                               ║
║  RECOMMENDED: Use Shape = 2.0 for most products (moderate wear-out)          ║
║                                                                               ║
║  Example Configuration:                                                      ║
║    DSM_Lifetime_Type_Cat_1  = Weibull                                        ║
║    DSM_Lifetime_Mean_Cat_1  = 25        (average lifetime in years)          ║
║    DSM_Lifetime_Shape_Cat_1 = 2.5       (wear-out pattern)                   ║
║                                                                               ║

║  TRIANGULAR MODE PARAMETER (Monte Carlo)                                     ║
║  ════════════════════════════════════════════════════════════════            ║
║  Purpose: Your best estimate / most likely value                             ║
║  Constraint: Min ≤ Mode ≤ Max                                                ║
║                                                                               ║
║  Distribution Shape (determined by Mode position):                           ║
║                                                                               ║

║                      /  \                                                     ║

║  Mode near Max:    ____  /\          Left-skewed (pessimistic tail)          ║
║                        \/                                                     ║
║                   Min Mode Max                                                ║
║                                                                               ║
║  ─────────────────────────────────────────────────────────────────────       ║
║                                                                               ║
║  EXAMPLE USE CASES:                                                          ║
║                                                                               ║
║  Case 1: Expert Estimate for Recycling Rate                                 ║
║    Min  = 0.25    (Pessimistic: policy fails, low investment)                ║
║    Mode = 0.40    (Most likely: current trend continues)                     ║
║    Max  = 0.65    (Optimistic: strong policy support)                        ║

║                                                                               ║

║    Min  = 1000    (Low scenario)                                             ║
║    Mode = 1500    (Centered - symmetric uncertainty)                         ║
║    Max  = 2000    (High scenario)                                            ║
║    → Symmetric: equal uncertainty in both directions                         ║
║                                                                               ║
║  Case 3: Conservative Engineering Estimate                                  ║

║    Mode = 0.18    (Near minimum - conservative expectation)                  ║
║    Max  = 0.30    (Upper bound from experiments)                             ║
║    → Right-skewed: expect low value, but some upside possible                ║

QUICK DECISION FLOWCHART:
═════════════════════════

For Weibull Shape:
──────────────────
Q: What type of failures do products have?
├─ Random failures throughout life → Shape = 1.0
├─ More failures early in life     → Shape = 0.5-0.9
├─ Typical wear-out pattern        → Shape = 1.5-2.5  ← MOST COMMON
└─ Sudden end-of-life (safety)     → Shape = 3.0-4.0

For Triangular Mode:
────────────────────
Q: What's your confidence in the estimate?
├─ Confident in low value, some upside  → Mode near Min
├─ Equal uncertainty both directions    → Mode at (Min+Max)/2
├─ Confident in high value, some risk   → Mode near Max
└─ Strong expert opinion at specific X  → Mode = X

COMMON MISTAKES TO AVOID:
═════════════════════════

❌ Weibull Shape = 0     → Will cause error (undefined)
❌ Weibull Shape > 5     → Unrealistic, too sharp end-of-life
❌ Triangular Mode < Min → Will cause error (invalid)
❌ Triangular Mode > Max → Will cause error (invalid)
❌ Mode = Min or Max     → Creates degenerate distribution

✅ Use Shape = 2.0 as default for typical products
✅ Use Mode = (Min+Max)/2 when uncertain about skewness
✅ Always check: Min ≤ Mode ≤ Max before running
