QUICK DECISION GUIDE:
═════════════════════

DSM - Which lifetime distribution?
-----------------------------------
→ Fixed           : Known exact lifetime (e.g., 20-year lease contract)
→ Normal          : Symmetric spread, moderate variation (StdDev < 80% Mean)
→ FoldedNormal    : Symmetric spread, large variation (safer than Normal)
→ LogNormal       : Some products last much longer (e.g., electronics)
→ Weibull         : Infant mortality or wear-out patterns

Monte Carlo - Which uncertainty distribution?
----------------------------------------------
→ normal          : Well-measured parameter with known mean and variation
→ uniform         : Only know min/max range, no preferred value
→ triangular      : Expert judgment with min/most likely/max
→ lognormal       : Positive-only values with right skew (rates, ratios)

EXAMPLES:
═════════

Example 1 - Building lifetime (DSM):
  Lifetime_Type = Normal
  Lifetime_Mean = 80
  Lifetime_StdDev = 12

Example 2 - Uncertain recycling rate (Monte Carlo):
  Distribution_Type = normal
  Mean = 0.35
  StdDev = 0.10
  Min = 0.0
  Max = 1.0

Example 3 - Expert estimate for future demand (Monte Carlo):
  Distribution_Type = triangular
  Min = 1000
  Mode = 1500
  Max = 2500
