Checking…

The link needs Zotero plus the free Better BibTeX plugin, which supplies the stable cite keys and the local search endpoint.
  1. Install and start Zotero 7 (desktop app — the browser connector alone is not enough).
  2. Download the Better BibTeX plugin file: ⬇ Get .xpi — take the zotero-better-bibtex-*.xpi asset of the latest release.
  3. In Zotero: Tools ▸ Plugins (Zotero 6: Tools ▸ Add-ons) ▸ gear icon ▸ Install Plugin From File… ▸ pick the downloaded .xpi.
  4. Restart Zotero, leave it running, then hit Test connection above.

Full plugin documentation: Better BibTeX installation guide. No Zotero available? Records can still be added by hand as assumptions & notes below.
